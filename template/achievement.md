# 成就回答模板

## 单个成就深度问

```
**<成就名>**（ID: <id>）

- **系列**：<系列名>
- **描述**：<desc>
- **稀有度**：<低/中/高>（<星琼数> 星琼）
- **隐藏**：<完全隐藏/描述隐藏/否>

**相关任务「<任务名>」**：（无相关任务则省略整块）
- **类型**：<任务类型>（<同行角色>）
- **所属版本**：<版本号>
- **接取方式**：<如何接取>（BWiki 中无此字段时改用「**任务条件**」）
- **剧情**：根据 BWiki「任务流程」总结完成方式
```

## 二选一成就

BWiki 标注「二选一」时使用：

```
**<成就名A> / <成就名B>**（二选一成就，<版本号> 版本）

---

**<成就名A>**（ID: <id>）
- **系列**：<系列名>
- **描述**：<desc>
- **稀有度**：<低/中/高>（<星琼数> 星琼）
- **隐藏**：<完全隐藏/描述隐藏/否>

**<成就名B>**（ID: <id>）
- （同上格式）

**完成方式**：
- 选择 <选项A> → 解锁「**<成就名A>**」
- 选择 <选项B> → 解锁「**<成就名B>**」
```
