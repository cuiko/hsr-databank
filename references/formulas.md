# 伤害公式体系（Damage Formulas）

> 本文件从 SKILL.md「2.6 伤害公式」抽离，供伤害计算类查询按需查阅。计算时以本文件为准。

> 计算伤害时**以下方公式为准**。`assets/formulas/` 目录的图片仅作可视化参考，不应作为计算依据。
>
> **⚠️ Agent 守则**：本节公式经过人工校验，**禁止自行修改**。如需修正或补充公式，必须先向用户说明改动内容并获得明确同意后才能执行编辑。

#### 常规伤害

```
最终伤害 = 基础值 × 特殊独立乘区
         × (1 + 增伤%)
         × (1 + 易伤%)
         × (1 - 造成伤害降低%)
         × (1 - 减伤1%) × (1 - 减伤2%) × ...
         × 抗性系数
         × 防御系数
         × 暴击乘区
         × 真实伤害乘区
```

- **基础值** = 攻击力 × 倍率（部分技能用生命值 / 防御力）
- **增伤**："使角色造成的伤害提高 X%"
- **易伤**："使目标受到的伤害提高 X%"
- **造成伤害降低**：施加在攻击者身上的 debuff，使其造成的伤害降低 X%（HSR 内文也叫「虚弱」效果，与韧性击破后的「虚弱状态」是不同概念）
- **减伤**：施加在受击者身上，多个减伤乘法叠加，最低降至 1%；未被弱点击破的敌人默认 10% 减伤
- **真实伤害乘区**：独立乘区，不与其他乘区稀释
- **特殊独立乘区**：技能/天赋/附加能力/星魂中出现「造成的伤害为原伤害的 X%」时，视为独立乘区——先按公式算出最终伤害，再乘以 X%。修饰对象多样，例如：
  - 特定技能：遐蝶 E1「【骸爪】…对其造成的伤害为原伤害的 120%/140%」
  - 角色全部伤害：那刻夏 E6「那刻夏造成的伤害为原伤害的 130%」
  - 角色部分技能：黄泉附加能力「奈落」「黄泉普攻、战技、终结技造成的伤害为原伤害的 115%/160%」
  - 某类伤害：海瑟音 E1「我方目标造成的持续伤害为原伤害的 116%」
  - 某类单位：长夜月 E1「我方忆灵造成的伤害为原伤害的 120%/…/150%」
  - 某个时机：爻光 E4「阿哈的额外回合中，我方全体角色欢愉技造成的伤害为原伤害的 150%」

#### 击破伤害 / 超击破伤害

```
击破伤害   = 击破基础值   × 属性倍率 × 特殊独立乘区 × (1+易伤) × (1+击破特攻) × (1+击破伤害提高) × 减伤 × 抗性 × 防御 × 真伤
超击破伤害 = 超击破基础值 × 超击破倍率 × 特殊独立乘区 × (1+易伤) × (1+击破特攻) × (1+击破伤害提高) × 减伤 × 抗性 × 防御 × 真伤
```

- **击破基础值** = `3767.55 × (韧性上限 / 40 + 0.5)`
- **超击破基础值** = `3767.55 × (技能最终削韧值 / 10)`
- **技能最终削韧值** = `基础削韧值 × (1 + 削韧值提高) × (1 + 弱点击破效率提高)`
- **属性倍率**：火/物理 2.0，风 1.5，冰/雷 1.0，量子/虚数 0.5
- 击破/超击破伤害**不受**常规增伤和「造成伤害降低」乘区影响

#### 欢愉伤害

```
欢愉伤害 = 基础值 × 欢愉倍率
        × (1 + 欢愉度%)
        × (1 + 增笑%)
        × 笑点乘区
        × (1 + 易伤%)
        × 减伤乘区 × 抗性系数 × 防御系数 × 暴击区 × 真实伤害乘区
```

- **基础值**：与角色等级直接相关，Lv80 固定 **7535.107**
- **欢愉倍率**：受角色技能倍率影响
- **欢愉度**：行迹加点等方式增加，提高欢愉伤害的乘区
- **增笑**：极少数效果提供
- **笑点乘区** = `1 + 6 × 笑点 / (笑点 + 200)`
- **不受**攻击力、属性伤害%、常规增伤影响（球绳的攻击球/属性伤害球均无效）
- 双爆、速度（影响阿哈频率）正常生效

#### 阿哈机制

「阿哈」是行动条上的面具单位。**欢愉命途角色越多，阿哈速度越快**：

```
阿哈速度 = 80 + a/5 + b/10 + c/20 + d/50
```
（a/b/c/d 为队伍中欢愉角色按速度从高到低排序，不足 4 人对应项视为 0）

**阿哈时刻**：阿哈行动时触发。先解除全体欢愉角色的控制类负面状态，随后所有可施放欢愉技的单位**按参演编号顺序**依次释放欢愉技；阿哈时刻结束后**消耗全部笑点**。

**参演编号**：欢愉角色释放欢愉技的固定顺序，编号越小越靠前；可在角色技能面板的欢愉技处查看。

**要有笑声**：若阿哈触发时**没有可释放欢愉技的角色**（如非欢愉队），阿哈会改为自己释放「要有笑声」——一段仅与笑点挂钩的欢愉伤害（公式中除笑点乘区外其他乘区视为 1）。常见于非欢愉主队的活动 / 挑战。

#### 笑点 vs 好活当赏

> **得笑点者得阿哈，得好活者得伤害**

| 名称 | 作用 | 触发时机 |
|------|------|---------|
| **笑点** | 累计欢愉伤害值，影响**阿哈打出的伤害**（笑点乘区） | 我方造成欢愉伤害时积累；阿哈时刻结束时清零 |
| **好活当赏** | 解锁/增强**欢愉角色技能本身的伤害**与额外效果 | 战斗开始时；阿哈时刻结束后 |

**好活当赏特性**：

- 仅施加在「欢愉」命途角色身上，**每位角色的效果不同**（如绯英解锁追加伤害、爻光解锁强化普攻、银狼LV.999 解锁盲盒攻击等）
- **基础持续 2 回合**，每位角色的保留时间独立计算（不同步消失）
- 角色秘技、星魂、专属机制可延长 / 加层 / 提速好活当赏（如爻光 E2、绯英 E6 可延长好活当赏持续时间）

#### 欢愉队循环节奏

```
战斗开始 → 全队获得【好活当赏】，开始积累笑点
   ↓
阿哈速度推进，行动条上阿哈面具到达
   ↓
触发阿哈时刻：欢愉角色按参演编号依次释放欢愉技 → 笑点清零，重新发放好活当赏
   ↓
回到积累笑点阶段（loop）
```


#### 持续伤害 (DoT)

```
持续伤害 = 基础值 × 特殊独立乘区
        × (1 + 增伤%) × (1 + 易伤%) × (1 - 造成伤害降低%)
        × 减伤 × 抗性系数 × 防御系数 × 持续伤害暴击区 × 真实伤害乘区
```

- 持续伤害与常规伤害的唯一区别是：原本的暴击区被替换为**持续伤害暴击区**（默认为 1，即不暴击），只有极少数效果能提供此乘区
- 基础值 = 攻击力 × 倍率（技能 DoT）；击破 DoT 的基础值与击破伤害公式相同

**DoT 叠加规则**：

- **同角色同技能**：后施加的 DoT **覆盖**先施加的（刷新持续时间和倍率）
- **不同角色**：各自独立共存，分别结算
- **击破 DoT 与技能 DoT**：同一属性的击破 DoT 和技能 DoT 可以**共存**，互不覆盖

**乘区差异**（常规 DoT vs 击破 DoT）：

| 乘区 | 技能 DoT | 击破 DoT |
|------|----------|---------|
| 攻击力 | ✓ | ✗ |
| 增伤 | ✓ | ✗ |
| 击破特攻 | ✗ | ✓ |
| 易伤 | ✓ | ✓ |
| 减伤 | ✓ | ✓ |
| 抗性 | ✓ | ✓ |
| 防御 | ✓ | ✓ |

> 持续伤害对于有条件的增伤、减防、易伤逻辑，如果没有额外修饰说明，**无法生效**。

#### 防御 / 抗性

```
抗性系数 = 1 - 抗性%    （-100% ≤ 抗性 ≤ 90%）

防御系数（攻方=角色） = (角色等级 + 20) / ((角色等级 + 20) + (敌人等级 + 20) × (1 - 降防% - 无视防御%))
防御系数（攻方=敌人） = (10 × 敌人等级 + 200) / (10 × 敌人等级 + 200 + 角色防御力)
```

- 角色攻击敌人时，敌人等级超过 100 按 100 计算；扑满须改为 `1.5 × 等级 + 30`
- **敌人默认抗性**：弱点 0%；非弱点 20%；面板特殊高抗 40% 或 60%
- 抗性 = 初始抗性 - 减抗 - 穿透（减抗与穿透加算、不互稀释）
- 添加弱点 ≠ 降低抗性，二者独立

#### 攻击判定与特殊伤害类型

- **「击中」需要攻击判定**：只有视为攻击的伤害才能触发「击中时」效果
- **「击杀」不需要攻击判定**：任何伤害（包括 DoT、击破伤害）造成的击杀都能触发「击杀时」效果
- **附加伤害**：使受击者额外受到 1 次伤害，不视为攻击，可暴击，无法削韧
- **追加攻击**：满足条件时自动触发的额外攻击，视为攻击，可暴击，可削韧
- **反击**：被攻击后触发的追加攻击，对攻击者施放 1 次额外攻击

#### 伤害分摊

部分敌人技能为群体攻击，受到的伤害由被击目标分摊：

- 分摊逻辑：先将基础伤害按目标数分裂，再对每个目标**独立**计算各自的减伤、防御、抗性等乘区
- **消耗生命不分摊**：消耗生命类效果（如刃天赋）按固定比例扣血，不受分摊影响
- **分摊承伤不算受击**：分摊伤害时，分摊方不视为「受到攻击」，不触发受击相关效果

#### 转换（转模）

转换指角色技能/行迹/星魂中"基于某一属性的一定比例获得另一属性"的机制（玩家社区简称"转模"）。堆叠源属性可按比例获得目标属性的收益。

**核心规则：转换所得不能被二次转换。** 角色的每个属性在底层分为**基本部分**和**额外部分**（注意"基本"与基础白值无关）：

```
实战属性 = 基本部分 + 额外部分
```

- **固定数值的增益**（遗器、直接 buff 等）加到基本部分
- **百分比转换**读取源属性的基本部分，写入目标属性的额外部分

转换公式只读取基本部分，而转换产物在额外部分，因此天然无法被二次转换。这不是 buff 先后顺序问题，而是数据结构设计。

> 例：万敌附加能力将**基本**生命上限转换为**额外**暴击率；星期日 E6 将**基本**暴击率转换为**额外**暴击伤害。万敌转换所得的暴击率在额外部分，星期日 E6 读不到，因此不会被二次转换。

**注意**：百分比 + 固定值混合的增益（如知更鸟协奏"自身攻击力 X% + 固定值"），固定值部分会被百分比部分牵连，整体写入额外部分，同样不能被二次转换。

**伤害结算时修改的数值也不参与转换**：如黄泉 E1、云璃 E6 的暴击率，通过 ModifyDamageData 在出伤时修改，不写入面板，转换读取面板所以无法触及。

**绑定攻击类型的增伤/爆伤只对对应类型生效**——"造成的战技伤害提高 X%"、"追加攻击暴击伤害提高 X%"等，作用范围被锁定在特定攻击类型上，无法转换到其他用途。

**可参与转换的数值**：直接给予的属性 buff（如翡翠 E2 的暴击率、镜流转魄的暴击率、诗人套效果等），因为它们不是由其他属性转换而来。

**倍率类型与攻击类型是两个正交维度**：

- **倍率类型**（伤害基于什么数值计算）：直伤（攻击力/生命值/防御力）、击破、超击破、**欢愉**
- **攻击类型**（以什么方式出伤）：普攻、战技、终结技、追加攻击、附加伤害、忆灵

两者可自由组合——例如绯英的"追加攻击的欢愉伤害"。增伤只作用于直伤（攻击力/生命值/防御力倍率），欢愉、击破、超击破倍率部分均不吃增伤。

> 标准天赋写法（"持有好活当赏时，释放 xx 技能对目标造成 X% 的欢愉伤害"）的欢愉伤害**不携带攻击类型标签**，因此攻击类型锁定的增伤/爆伤/易伤（如"追加攻击暴击伤害提高 X%"、"终结技易伤 X%"）对欢愉伤害**无效**；时机条件的 buff（如"释放终结技时造成的暴击伤害提高 X%"）对欢愉伤害**生效**。
>
> 例：绯英狐狸老师的追加攻击中，直伤部分吃追击爆伤，欢愉伤害部分不吃；但"释放追加攻击时暴伤提高"两者都能吃到。
>
> **例外**：银狼LV.999 天赋"强化普攻的技能伤害**改为**相同倍率的欢愉伤害"属于类型替换，替换后的欢愉伤害保留普攻的攻击类型标签，可以吃到普攻类型锁定的 buff。

**代表性转换示例**：

| 角色 | 源属性 | 目标属性 | 效果 |
|------|--------|---------|------|
| 银狼 lv999 | 速度 | 欢愉度 | ≥ 160 后 +50%，每超 1 点 +2%，上限 100 点 |
| 爻光 | 速度 | 欢愉度 | ≥ 120 后 +30%，每超 1 点 +1%，上限 200 点 |
| 风堇 | 速度 | 治疗量/暴击伤害 | > 200 后每超 1 点治疗量 +1%（上限 200 点）；E4 额外每超 1 点爆伤 +2% |
| 万敌 | 生命上限 | 暴击率 | > 4000 后每超 100 点暴击率 +1.2%，上限 4000 点 |
| 波提欧 | 击破特攻 | 暴击率/暴击伤害 | ×10%/×50%，上限 30%/150% |
| 星期日 | 暴击率（溢出） | 暴击伤害 | 超 100% 后每溢出 1% → +2% 暴击伤害 |
| 花火 | 暴击伤害 | 暴击伤害（队友） | 花火暴击伤害 ×30% → 队友暴击伤害 |
